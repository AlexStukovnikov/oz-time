(static) duration(amount, unit) → {Duration}

Description:

  • Создаёт и возвращает экземпляр Duration из числа и фиксированной единицы времени.

Source:
  • modules/duration.js, line 155
Example
import { duration } from '@alexstukovnikov/oz-time';

const value = duration(2, 'hour');
console.log(value.asMinutes()); // ожидаемый результат: 120
