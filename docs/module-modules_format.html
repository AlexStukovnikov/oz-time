Methods

(static) format(time, template, localeopt) → {string}

Description:

  • Возвращает строковое представление экземпляра OzTime по заданному шаблону с токенами.

    Поддерживаются токены YYYY, YY, MMMM, MMM, MM, M, dddd, ddd, DD, D, HH, H, hh, h, mm, ss, SSS и A.

Source:
  • modules/format.js, line 109
Example
import { format, fromISO } from '@alexstukovnikov/oz-time';

const time = fromISO('2024-05-25T12:00:00Z', 'UTC', 'ru-RU');
console.log(format(time, 'DD.MM.YYYY HH:mm')); // ожидаемый результат: 25.05.2024 12:00
